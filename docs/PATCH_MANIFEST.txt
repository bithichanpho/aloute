# ALOUTE backend working-tree manifest

This repository is maintained as source code on the current Git branch. It is no longer distributed as a delta ZIP over an unnamed archive, so old file counts and manual copy/delete instructions are intentionally removed.

## Current backend baseline

- Java 21 and Spring Boot 4.1.1.
- PostgreSQL schema managed by Flyway through `V20261101`.
- MongoDB indexes managed idempotently by `deploy/migrations/mongo-indexes.js`.
- Redis used for cache, distributed rate limiting, presence and call state according to environment policy.
- Mongo replica-set transactions used where document deletion and durable media tombstones must commit together.
- PostgreSQL outbox jobs used for cleanup that crosses PostgreSQL, MongoDB and Cloudinary.

## Main remediation areas

- Request validation, authentication/OTP, token revocation and trusted-proxy handling.
- Cursor pagination and query-budget improvements for feed, profile, group, chat and notifications.
- Durable notification and account/community cleanup jobs.
- Community-manager authorization and server-wide `ROLE_HOST` dashboard.
- Repost presentation, group unread state and removed story functionality.
- Central media lifecycle, hidden-post reconciliation and retryable Cloudinary deletion.
- Bounded asynchronous moderation with lease recovery for posts and comments.
- Explicit Redis outage behavior for cache, rate limits and presence.
- Paginated community/search APIs, database-aggregated HOST metrics and audited ADMIN account control.

## Validation commands

```powershell
mvn clean test
mvn verify
.\deploy\scripts\validate-empty-schema.ps1
```

The schema script accepts only a disposable PostgreSQL database on loopback. Do not run it against Supabase or another shared database.
