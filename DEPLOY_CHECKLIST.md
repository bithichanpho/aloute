# ALOUTE deployment checklist - Windows + Supabase

- [ ] Java 21 available (project targets Java 21)
- [ ] Docker Desktop running
- [ ] Supabase project created and database password known
- [ ] Supabase Connect -> Session pooler -> JDBC string copied
- [ ] `.env` created from `.env.example`
- [ ] `DB_URL` set with `sslmode=require`
- [ ] `DB_SCHEMA=public` (or an existing schema)
- [ ] MongoDB Atlas URI set
- [ ] Cloudinary credentials set
- [ ] Gmail App Password set
- [ ] JWT secret set
- [ ] `docker compose up -d --build` succeeds
- [ ] `docker compose ps` shows `aloute-app` healthy/running
- [ ] `http://localhost:8080` opens locally
- [ ] Registration/login works
- [ ] Email verification/reset works
- [ ] Image upload works
- [ ] Chat/WebSocket works
- [ ] For LAN: reverse proxy and firewall configured
- [ ] For Internet: domain DNS points to your public IP
- [ ] HTTPS configured
- [ ] `APP_COOKIE_SECURE=true` after HTTPS works
- [ ] `APP_CORS_ALLOWED_ORIGINS` set to the exact HTTPS origin
- [ ] Supabase backup/migration strategy defined
